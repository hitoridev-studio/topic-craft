13体の AI が Git の履歴だけを共有し、12日間研究し続けた

NVIDIA の論文 Agora は、AI エージェントの研究成果（結果・洞察・仮説・検証）を Git のコミットとして積む共有メモリを提案し、13体のコーディングエージェントに担当も司令塔もなしで 12日間研究させた記録を報告している。1,703 件の投稿で「訓練なしのモデル初期化」の評価値を 3.39 から 1.899 bits/byte へ下げ、互いの再現 165 件に失敗は一つもなかった。

論文: Zhang ほか（NVIDIA）, arXiv:2609.180942026-09-16 投稿

何が起きたか

課題は、141 個の学習済みモデルの重みと順伝播だけを使って、どのモデルとも次元が一致しない 14 層の注意＋状態空間（SSM）ハイブリッド（1億1957万パラメータ）を初期化すること。訓練データも勾配更新も禁止。評価は次トークン損失を UTF-8 バイト数で割った bits per byte（bpb）で、乱数初期化が 3.3923、学習済み GPT-2 124M が約 1.0。

ワーカーは Claude Code（Claude Opus 4.7）と Codex（GPT-5.5）のセッション 13 アカウント。与えたのは 2 ページの brief と評価器と共有グラフだけで、手法も役割も指示していない。各セッションは、analyze を読んで親を選び、そのコミットを checkout して 1 つ変え、評価し、再現に要るものをコミットして push する、を繰り返した。4月26日から5月8日までの 11日19時間で 1,703 件（採点済み結果 1,124・洞察 284・仮説 203・検証 165・報告 1）。

最良は 1.899044 bpb で、乱数初期化と GPT-2 の差の 62% を詰めた。その祖先は 145 コミット・15 アカウントにまたがり、親エッジ 144 本のうち 115 本がアカウント境界を越える。一人で組み上げた手法ではない。検証 165 件はすべて著者と別のアカウントによるもので、失敗の報告はゼロだった。

仕組み

投稿の一つひとつが Git のコミットで、親エッジが「その上に積んだ」を意味する。コードを伴う投稿はリポジトリの状態を丸ごと持つので、どの主張も checkout して再実行できる。状態は Git だけで、検索用の SQLite の索引も分析ビューも Git の履歴から作り直せる。

品質は投票ではなく下流の証拠で決める。ある投稿の評価値は「別アカウントがその上に積んだ投稿の重みの和」で、自分の続きは数えない。検証は確認 +20・部分 +10・失敗 −20、結果・洞察・仮説は +5。analyze はリーダーボードのほかに、最も積まれたノード・手薄な有望株・未検証・未着手の仮説といったビューを一度に返し、意味クラスタが取れると多様性つきの UCB で候補を exploit・explore known・explore novel の 3 枠に分けて見せる。

評価値  S(u) = Σ_{v: u→v} 1[a(u) ≠ a(v)] · w(v)
        別アカウント a(v) が u の上に積んだ投稿 v の重み w の和。自分の続きは数えない

候補    U(v) = 100·Q(v) + C·√( log(N+1) / (n(v)+1) ) + 100·D / √(1+ρ(v))
        Q: 品質の百分位   n: v の上に積まれた数（N は全体）   ρ: 説明が近い重複の数
        C は指標の分布が最良付近に密集するほど大きくなる

5日間の一極集中と、1回の介入

推移は極端に前のめりだ。初日に出た統計的プライアの 18 件で総減少の 98% が出て、残りの 1,106 件が見つけたのは 0.03。5月2日、活動の 3 分の 1 以上が 1 つの意味クラスタに集まり、リーダーボードは止まっていた。著者らはここで一度だけ手を入れ、クラスタリングと多様性のビューと UCB を配備した。翌朝、支配的なクラスタではなく手薄な SSM のクラスタを選んだワーカーが最初の 1.90 未満を出した。介入はこの 1 回で、タスクの割り当ても承認もしていない。

並行再発見も多い。別アカウントが同じスコアを出した 696 組のうち 63% は 1 時間以内、80% は 6 時間以内。共有リーダーボードは重複作業を止めなかった、と論文は書く。

見つけた手法

Stage AGPT-2 の語彙を共有する 6 つのドナーに、全 50,257 トークン × 28 通りの 1 トークン文脈で次トークンの log-softmax を出させ、固定の重みで混ぜて 50257×50257 の遷移表を作る。列ごとの平均 u を分けて中心化し、rank 671 の randomized SVD で分解。左特異ベクトルを入力埋め込みに、右特異ベクトル×特異値を出力ヘッドに、次元 0 に u を置き、副層はすべて零にする。「14 層の網に格納されたバイグラムモデル」ができる。 Stage B隠れ状態の 96 次元の帯に対する疎で決定的な編集。注意層は 1 つの帯の因果平均に、層 0 の SwiGLU には GPT-2 small の第 1 MLP の SVD 射影を、SSM は選択経路を切って畳み込みに。各定数は「当時の最良に 1 つ変更を加えて評価が改善したから残った」もの。

確かめたこと

算術62% は (3.3923 − 1.899044) / (3.3923 − 1.0) = 0.6242。98% は (3.3923 − 1.9304) / (3.3923 − 1.899044) = 0.9790。残りは 1,124 − 18 = 1,106 件で、差は 0.031。 Stage AV = 24 の乱数の遷移表で Algorithm 1 の 8〜11 行を組み、副層をすべて零にした網の logits（埋め込み × ヘッドT × √d）を見た。d = V で遷移表と最大誤差 1.7×10-14 で一致し、d < V では誤差が落とした特異値の二乗和の平方根に一致する（Eckart–Young。d = 4 で 31.79、20 で 3.00）。文脈を変えても現在のトークンが同じなら logits は同じ。中心化した表は列和が 0 なので rank ≤ V − 1 で、次元 0 を u に空けた rank d − 1 がちょうど足りる。 テスト同じディレクトリの factorized-bigram.test.mjs（Node・依存なし・7 件）。SVD は片側ヤコビ法。

注意

論文自身が「因果は未確定」と書いている。同じモデルと計算資源で Agora 無しの対照実験はしておらず、付録 C にその比較計画を置いている。一極集中から抜けたのも、人間が地図（クラスタのビュー）を配備した後だ。

全部が同じ 200 テキストの開発用評価器で選ばれている。信用すべきは 3.39 → 1.90 の改善幅で、末尾の桁ではない（最後の変更の効果は 9×10-6 で、ハードウェア間の差 1.3×10-3 より小さい）。著者らは勝ち筋を再実行しておらず、コードやトレースの公開 URL は論文に無い（読んだ範囲）。
