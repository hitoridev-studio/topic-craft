# topic craft

hitoridev studio の作品カタログ。毎朝の技術動向（約 1,500 件を 10 本に絞ったもの）から 1 本を選び、その日のうちに「もの」（ブラウザで動く 1 ファイル）か「記事」（一次情報を読んで書いたまとめ）にして、ここに置く。

- 一覧: https://hitoridev-studio.github.io/topic-craft/
- 各成果物: `works/<日付>-<名前>/index.html`（依存なし。ファイルを開けば動く）
- 数字と主張は出典の範囲だけ書く。出典は各ページの末尾。

## 作り方

1. 朝の技術動向から 1 本を選ぶ
2. 一次情報（論文・記事・コード）を読む
3. 要点をブラウザで動くもので見せられるなら「もの」、そうでなければ「記事」にする
4. 「もの」は 8 秒の画面録画を付け、X に出す
