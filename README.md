# topic craft

hitori が、新しい技術の論文や記事を題材に作った、ブラウザで動くデモと解説。

- サイト: https://hitoridev-studio.github.io/topic-craft/
- X: https://x.com/botchi_the_dev
- 作品は `works/<日付>-<名前>/`。使い方・ファイル・テスト・出典は、それぞれの `README.md` にある。
- ページは、リポジトリごと落として `index.html` をブラウザで開けば動く（見た目と図は `assets/` を使う）。計算のコードは、ほかのパッケージを使わない。
- 出典は各ページの末尾に置く。取り上げた論文・記事の権利はそれぞれの著者にある。
